# Settings

The Settings section allows you to customize data collection and metadata handling for your series in Shoko. These
settings enable you to control the type and amount of information Shoko collects, ensuring that it only downloads and
stores what's necessary. Open them with the gear icon in the top right of the Web UI.

Settings are split into tabs, each documented on its own page:

| Tab | What it covers |
| --- | --- |
| [General](/shoko-server/settings/general) | Version information, themes, notifications and logs. |
| [Import](/shoko-server/settings/import) | Managed folders, import options and how Shoko notices new files. |
| [Hashing & Release](/shoko-server/settings/hashing-and-release) | Hashing, release providers and release management. |
| [AniDB](/shoko-server/settings/anidb) | AniDB login, downloads, MyList and update frequencies. |
| [Metadata](/shoko-server/settings/metadata) | Metadata sources and their providers, auto-linking, images, purging and cross-references. |
| [Collection](/shoko-server/settings/collection) | How series are grouped and which title languages are used. |
| [Integrations](/shoko-server/settings/integrations) | Connections to other services, such as Plex. |
| [Plugin Management](/shoko-server/settings/plugin-management) | Installing, updating and configuring Shoko Server plugins. |
| [User Management](/shoko-server/settings/user-management) | Users, passwords, avatars and tag restrictions. |
| [API Keys](/shoko-server/settings/api-keys) | Keys issued to plugins and other programs. |

Most changes are saved with the **Save** button at the bottom of each tab.
